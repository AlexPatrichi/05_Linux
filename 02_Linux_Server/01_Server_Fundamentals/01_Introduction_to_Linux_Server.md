## Overview

**Linux Server** refers to a server operating system built around the open-source Linux kernel. 

Linux-based server distributions are widely used across the world in enterprise environments, cloud computing, web hosting and network infrastructure.

Linux server distributions can function as a **Network Operating System (NOS)**, providing centralised management of network resources, users, services and security.

Unlike desktop operating systems, which primarily support individual users, Linux servers are designed to deliver services and resources to multiple users and devices across a network.

Linux servers are commonly used to:

- **Manage users and groups** — Control user accounts, group membership and access permissions.
- **Provide network services** — Deliver services such as DNS, DHCP, SSH and web hosting.
- **Share files and resources** — Enable users and devices to access shared directories and network resources.
- **Manage security** — Implement authentication, permissions, firewalls and access controls.
- **Host applications** — Run websites, databases and business applications.
- **Support remote administration** — Allow administrators to manage servers remotely using secure command-line tools.

Linux is particularly valued for its **stability, security, flexibility and open-source development model**, making it a popular choice for organisations of all sizes.
